# DDL 参考模板索引

本目录存放各数据库的 DDL 语法规范和模板。DDL 设计阶段根据项目的目标数据库按需加载。

## 文档清单

| 文档 | 目标数据库 |
|------|-----------|
| `dameng8.md` | 达梦8（DM8） |
| `mysql.md` | MySQL 5.7+ / 8.x |
| `postgresql.md` | PostgreSQL 12+ |

## 加载方式

1. 在启动 DDL 设计前，确认项目使用的数据库类型（已在 backend-dev 启动阶段确认）
2. 只加载对应数据库的模板文件
3. 如果项目使用其他数据库，向用户确认语法差异和类型映射规则

## 通用原则

无论使用哪种数据库，以下原则一致遵循：

- 表名 `t_模块_实体`，字段名小写下划线
- 每张表必须包含公共字段：`id`、`create_by`、`create_time`、`update_by`、`update_time`、`del_flag`、`remark`
- **所有表和字段必须添加中文注释**，枚举字段列出所有可选值
- 主键使用 `BIGINT`，应用层生成（雪花 ID / UUID 等）
- 索引命名：唯一索引 `uk_表名_字段`，普通索引 `idx_表名_字段`
- 每个索引必须标注服务于哪个查询场景
