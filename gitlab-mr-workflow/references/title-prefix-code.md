# 标题前缀码规范（议题 / MR）

适用范围：**新建**的议题与 MR；存量标题不追溯、不为合规而批量改名。合规口径以本文为准——本文未列出的前缀形式视为不合规。建单 / 开 MR 前跑 `scripts/title-lint.py`，它直接解析本文的组合表，改表即改规则。

## 议题标题：`[类别][状态?] 摘要`

- **类别**（必填，单选）：需求 / 缺陷 / 技术债 / 测试对齐 / 配置 / 调查结论 / 复核
- **状态**（可选，单选）：待拍板 / 待确认 / 生产 / 联调
- 摘要＝对象 + 改动，一句话，不以句号结尾；子议题在摘要开头写「<父议题主题>·子议题 n/N：」

| 状态 | 含义 |
|---|---|
| 待拍板 | 方案有分叉，需决策者选定才能开工 |
| 待确认 | 性质或归属未定（疑似缺陷、归属不清的遗留物） |
| 生产 | 生产环境已发生的故障 |
| 联调 | 与外部联调时产生、或服务于联调的事项 |

**类别 × 状态合法组合表**（✅＝允许；—＝不适用，按下一张表改写）：

| 类别 \ 状态 | 待拍板 | 待确认 | 生产 | 联调 | 无状态 | 示例 |
|---|---|---|---|---|---|---|
| 需求 | ✅ | — | — | ✅ | ✅ | `[需求][待拍板] REQ-012 使用已订阅资源参与 Agent 调用` |
| 缺陷 | — | ✅ | ✅ | ✅ | ✅ | `[缺陷][生产] SDK-05 下载产出的 ZIP 容器非法` |
| 技术债 | — | ✅ | — | — | ✅ | `[技术债][待确认] ModelParam 默认值出站键跨域分叉` |
| 配置 | — | — | — | ✅ | ✅ | `[配置][联调] SDK-04/05 dev 密钥本地配置修正` |
| 测试对齐 | — | — | — | — | ✅ | `[测试对齐] SDK 查询裁剪 3 用例更新` |
| 调查结论 | — | — | — | — | ✅ | `[调查结论] SDK 代码结构与规范对齐评估` |
| 复核 | — | — | — | — | ✅ | `[复核] T3.2 ZIP 路径穿越用例核对` |

**不适用组合的替代写法**：

| 不适用的组合 | 原因 | 改用 |
|---|---|---|
| 需求 × 生产 | 生产上的问题是故障 | `[缺陷][生产]` |
| 需求 × 待确认 | 需求的不确定＝方案未定 | `[需求][待拍板]` |
| 缺陷 × 待拍板 | 缺陷不需要选方案 | 疑似缺陷用 `[缺陷][待确认]` |
| 技术债 × 待拍板 / 生产 / 联调 | 技术债的不确定只有归属 | `[技术债][待确认]`；生产故障用 `[缺陷][生产]` |
| 配置 × 待拍板 / 待确认 / 生产 | 配置变更无歧义 | 无状态 `[配置]`；生产故障用 `[缺陷][生产]` |
| 测试对齐 / 调查结论 / 复核 × 任一状态 | 这三类是工作性质，不带状态位 | 去掉状态位 |

## MR 标题：`type(scope): 摘要`

- **type**（必填，单选）见下表；**scope**（可选）＝受影响模块的小写短名（`sdk` / `resource` / `config` / `gateway`），跨模块时省略
- 摘要与议题同口径；`Closes #N` / `Refs #N` 写**正文首行**，不进标题（纯文档 MR 同样要带）
- `Draft:` 前缀＝仍在自测、不进评审；合并前摘除（见 SKILL.md「Merging an MR — always verify」节）
- 禁止：分支名当标题（`Feature/wangxq`）、卡号当标题（`Issue #34 …` / `T0.1 …`），卡号写进 scope 或正文；一个 MR 只做一种 type，混类型改动拆 MR

| type | 用于 |
|---|---|
| `feat` | 新增或变更对外行为（接口、功能、契约） |
| `fix` | 修复缺陷（对应 `[缺陷]` 议题） |
| `refactor` | 不改对外行为的内部重构 |
| `docs` | 仅文档、注释、契约文本 |
| `test` | 仅测试代码 |
| `chore` | 构建、依赖、配置、脚本 |
| `revert` | 回滚已合并的 MR（正文注明被回滚的 MR 号） |

## 校验：`scripts/title-lint.py`

| 用法 | 说明 |
|---|---|
| `python3 scripts/title-lint.py issue "<标题>"…` | 校验议题标题 |
| `python3 scripts/title-lint.py mr "<标题>"…` | 校验 MR 标题 |
| `python3 scripts/title-lint.py < 清单` | stdin 逐行 `issue<TAB>标题` 或 `mr<TAB>标题`，也认 `#32<TAB>…` / `!73<TAB>…` |

违规逐条输出 `类型 | 标题 | 原因`，末行 `合规 N / 违规 M`。退出码：0 全部合规 / 1 有不合规 / 2 用法错误或组合表解析失败。
